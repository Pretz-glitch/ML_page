## Implications for the project

1. **Within-station scaling is mandatory.** 3 of 11 features have at least half their variance between stations, so a pooled detector would largely learn station identity.
2. **Attribution must be interpreted by feature family.** The strongest pair is `T_mean`–`T_min` at r = 0.996; within-family substitution will make single-column attributions unstable.
3. **The split is temporal and must not be shuffled.** The table uses days 0–422 for training and 423–704 for testing.
4. **No imputation is needed.** The feature matrix has 0 missing values.
